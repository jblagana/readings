# GPU-Accelerated Grid Optimization

## Review and learning package

A structured path from electrical-engineering fundamentals to GPU kernels, grid optimization, DERMS, and a practical PhD roadmap.

### Choose a path

- **Fast lane:** start with the [literature review](03_gpu_grid_optimization_review.html), use the [glossary](04_glossary.html) as needed, then follow the [Scopus search guide](05_scopus_search_guide.html).
- **Deep track:** read [fundamentals](01_fundamentals_bridge.html), [GPU basics and kernels](02_gpu_basics_and_kernels.html), the [literature review](03_gpu_grid_optimization_review.html), [glossary](04_glossary.html), [Scopus guide](05_scopus_search_guide.html), and [PhD roadmap](06_phd_roadmap.html).
- **PhD preparation:** read the [fundamentals](01_fundamentals_bridge.html), run and modify the examples in [`cuda_kernels/`](cuda_kernels/), then use the [review](03_gpu_grid_optimization_review.html) and [roadmap](06_phd_roadmap.html) to choose a direction.
